# Support

For app help, start with [troubleshooting](docs/TROUBLESHOOTING.md) and the [latest release](https://github.com/Kavishcan/momentum/releases/latest).

## Bugs and ideas

Use the [issue forms](https://github.com/Kavishcan/momentum/issues/new/choose). For a bug, include:

- Momentum version, macOS version, and Apple Silicon or Intel.
- What you tried, what you expected, and what happened instead.
- Short reproduction steps and a screenshot with personal task text removed.
- Whether it still happens in the latest release.

Use synthetic task names in examples. Please keep databases, backups, personal logs, and credentials out of public issues. For a security problem, use the private contact in [SECURITY.md](SECURITY.md).

## Common starting points

| Symptom | Start here |
| --- | --- |
| Download or launch problem | [Install and launch](docs/TROUBLESHOOTING.md#install-and-launch) |
| Notification does not appear | [Reminder checks](docs/TROUBLESHOOTING.md#reminders) |
| App window disappears but timer remains | [Window and timer behavior](docs/TROUBLESHOOTING.md#windows-and-focus) |
| Missing data or a migration error | [Local data and recovery](docs/TROUBLESHOOTING.md#local-data-and-recovery) |
| Questions about stored information | [Privacy notes](docs/PRIVACY.md) |

Momentum is independently maintained on a best-effort basis. A clear reproduction is more useful than a large unfiltered log. Sponsorship helps sustain the work; it does not guarantee a support deadline or feature.
